LSP Suite

Command AutoLISP untuk drafting interior. Isinya untuk pekerjaan yang berulang: memberi nomor sheet, menyamakan judul dengan daftar isi, dan menggambar spec leader yang tetap terhubung dengan labelnya.

KodeAtas permintaan

Kenapa saya membuat ini

Shop drawing interior mengulang pekerjaan kecil yang sama ratusan kali. Setiap sheet punya kode dan judul, diketik sekali di daftar isi lalu diketik lagi di sheet-nya. Setiap material butuh leader dan deskripsi. Kalau ada sheet tambahan atau klien mengganti material, semuanya diulang manual.

Command-command ini dibangun di atas satu ide: daftar isi (TOC) di model space adalah satu-satunya sumber data. Kode sheet, nama layout, judul sheet, dan deskripsi material cukup diketik sekali di TOC, lalu command-nya menyalin ke tempat lain. Spec leader menyimpan hubungan tersembunyi antara ketiga bagiannya, jadi bisa dipindah, digambar ulang, atau diganti di seluruh gambar dalam satu langkah.

Saya drafter interior. Saya merancang setiap command: apa yang dikerjakan, apa yang ditanyakan, dan bagaimana cocoknya dengan cara satu set gambar dibuat. Saya membangunnya dengan AI coding agent dan memakainya di proyek nyata.

Cara pakai

Load file .lsp dengan APPLOAD. Lalu ketik nama command di command line dan tekan Enter, sama seperti mengetik LINE atau COPY.

Sebagian besar command mencari block dan attribute berdasarkan nama. Daftar block di bagian bawah berisi semuanya.

Alat cepat

Ketik command-nya lalu jawab pertanyaannya.

ADMenomori block sesuai urutan klik

Pilih block sumber, lalu klik block lain satu per satu. Semua angka di semua attribute naik sebesar step dikali jumlah klik. Dengan step 1, klik pertama dapat +1, klik kedua +2, dan seterusnya. Nilai lama di block tujuan tidak dipakai. Nol di depan tetap dipertahankan, jadi FURN-01 menjadi FURN-02.

  1. Step per klik. Enter berarti 1. Bisa negatif.
  2. Pilih block sumber.
  3. Klik block tujuan secara berurutan. Enter untuk selesai.

Attribute skala (SKALA) tidak pernah diubah.

CCMenyalin judul gambar

Menyalin judul gambar dari satu block JUDUL ke block lain. JUDUL adalah label judul di bawah setiap gambar di model space.

  1. Pilih block JUDUL sumber.
  2. Klik block tujuan. Enter untuk selesai.

DBFrame dan judul untuk gambar baru

Menggambar frame halaman di layer Defpoints, yang tidak ikut di-plot, dan menaruh block judul JUDUL2 di tengahnya. Ukuran keduanya mengikuti skala yang dimasukkan: frame-nya 340 × 287 dikali skala, jadi 6800 × 5740 di 1:20.

  1. Angka skala, misalnya 20 untuk 1:20. DB mengingat jawaban terakhir.
  2. Judul gambar. Ketik s, v, d, atau f untuk SECTION 1-1, VIEW 1, DETAIL A, atau FRONT VIEW. Teks lain dipakai persis seperti yang diketik. Enter membiarkannya kosong.
  3. Klik sudut kiri atas frame.

Block judul diisi judul dan skalanya, ditulis 1:20.

DDMengganti skala dimension

Mengatur skala dimension (DIMSCALE). Pilih dimension sebelum menjalankan DD, dan dimension itu ikut berganti skala.

Pertanyaan: skalanya, misalnya 50 untuk 1:50.

DIVV / DIVHMembagi kotak menjadi ruang sama besar

Untuk tampak kabinet. DIVV menambah sekat vertikal, DIVH menambah ambalan horizontal. Setiap sekat digambar sebagai dua garis dengan jarak setebal sekat, dan semua bukaan hasilnya sama besar.

  1. Jumlah ruang. Default 3.
  2. Tebal sekat. Default 20.
  3. Pilih outline kabinet.

DSGaris bertahap untuk sisi melengkung

Menggambar garis-garis sejajar di samping garis acuan, dengan jarak yang makin lebar sesuai rasio. Cara biasa untuk menampilkan permukaan lengkung di gambar tampak.

  1. Pilih garis acuan.
  2. Jumlah garis. Default 8.
  3. Rasio pertambahan. Default 1.35.
  4. Jarak ke garis terakhir. Tanda plus/minus menentukan sisi. Default 100.

Jawaban terakhir dipakai sebagai default untuk berikutnya.

NUMDeretan angka

Menulis angka berupa teks dalam satu baris, dari kiri ke kanan, dengan layer dan text style yang sedang aktif.

Pertanyaan: berapa angka, angka awal (Enter berarti 1), titik awal.

PFMenaruh daftar furnitur

Membuat daftar furnitur di halaman index shop drawing furnitur. Meng-insert satu kolom block FURNLIST dengan kode seperti CA1, CA2... dan judul seperti cabinet 1, cabinet 2....

Pertanyaan: prefix kode, judul dasar, nomor awal, nomor akhir, titik insert pertama.

QGanti layer dengan satu huruf

Ketik satu huruf dan layer itu jadi layer aktif. Kalau ada objek yang dipilih sebelum menjalankan Q, objeknya yang pindah ke layer itu, dan layer aktif tidak berubah.

TOC dan layout

Command-command ini menjadikan daftar isi (TOC) di model space sebagai daftar induk semua sheet. Judul sheet cukup diketik sekali di TOC, lalu command-nya menyalin judul itu ke kop layout yang sesuai.

Block TOC

TOC adalah satu kolom block TOC di model space. Setiap block adalah satu baris dengan dua attribute:

TagIsiContoh
PAGECODEKode sheet. Harus sama dengan nama tab layout (huruf besar/kecil tidak berpengaruh).FURN-03
PAGETITLEJudul sheet yang tampil di kop.Tampak kabinet 3

Block TOC juga menyimpan kode spec yang dibaca SL. Penjelasannya ada di kode spec.

Alur kerja

Mulai dengan satu layout untuk setiap sheet, dengan urutan yang benar.

  1. Taruh barisnya. Di model space jalankan PT dengan prefix FURN, awal 1, akhir 12. Hasilnya FURN-01 sampai FURN-12 dengan judul kosong.
  2. Isi judulnya. Double-click baris pertama dan ketik judulnya. Lalu pakai CT untuk menyalin apa adanya, atau CP / CPP untuk menyalin dengan angka yang naik setiap klik.
  3. Ganti nama layout. Jalankan WQB dengan prefix FURN- dan awal 1. Nama tab menjadi FURN-01 sampai FURN-12, sama dengan TOC.
  4. Sinkronkan setiap sheet. Atur skala viewport, lalu jalankan WS di layout itu. Skala ditulis ke kop dan judul diambil dari TOC. Untuk sheet tanpa skala jalankan WSS.
  5. Menyisipkan sheet belakangan. Pilih baris-baris setelah sheet baru lalu jalankan CTB dengan +1 untuk menggeser kodenya. Jalankan WQB lagi, lalu WS di sheet yang berubah.

PTMenaruh baris TOC

Meng-insert satu kolom block TOC dengan kode FURN-01, FURN-02... dan judul kosong.

Pertanyaan: prefix, nomor awal, nomor akhir, titik insert pertama.

CT / CP / CPPMenyalin judul TOC

Ketiganya menyalin PAGETITLE dari block TOC sumber ke block yang diklik setelahnya. Pilih sumber, klik tujuan, Enter untuk selesai. Bedanya ada di angka dalam judul:

CommandAngkaSumber Lantai 2 Kabinet 4 menghasilkan
CTtetapLantai 2 Kabinet 4, Lantai 2 Kabinet 4...
CPsemua +1 per klikLantai 3 Kabinet 5, Lantai 4 Kabinet 6...
CPPsemua kecuali yang pertama +1 per klikLantai 2 Kabinet 5, Lantai 2 Kabinet 6...

CW / CTBMengubah kode TOC

CW mirip CP tapi untuk PAGECODE: pilih sumber, lalu setiap tujuan mendapat kode +1, +2, dan seterusnya. Nol di depan tetap ada, jadi FURN-09 menjadi FURN-10.

CTB adalah versi banyak sekaligus. Pilih block sebanyak apa pun dengan window, masukkan angka (default 1, boleh negatif), dan angka itu ditambahkan ke nomor di akhir setiap kode. FURN-05 menjadi FURN-06.

WQBGanti nama semua layout

Mengganti nama setiap tab layout, sesuai urutan tab, menjadi prefix + nomor dua digit.

Pertanyaan: prefix (boleh kosong), nomor awal.

WS / WSSSinkron skala dan judul ke sheet

Jalankan di tab layout. Tidak ada pertanyaan.

  1. Skala. WS membaca skala viewport dan menulis 1:50 (atau berapa pun skalanya) ke attribute SCALE di kop. WSS menulis N.T.S.
  2. Judul. Mencari block TOC di model space yang PAGECODE-nya sama dengan nama tab ini, lalu menulis PAGETITLE-nya ke KOPTITLE di kop.

Spec dan leader

Cara kerja spec leader

Satu spec leader terdiri dari tiga objek: lingkaran kecil di benda yang diberi label, polyline putus-putus, dan block SPEC berisi kode dan deskripsi. SL menggambar ketiganya dan memberi ID tersembunyi yang sama (XData). Dengan ID itu, RR, RZ, RC, dan EE bisa menemukan dua objek lainnya saat salah satunya dipilih.

Kalau leader di-copy, ID-nya ikut tersalin, jadi leader baru selalu dibuat dengan SL.

Kode spec

SL mengisi deskripsi dengan mencari kode spec di block TOC di model space. Setiap material punya satu baris TOC: kode di PAGECODE, deskripsi lengkap di PAGETITLE.

PAGECODEPAGETITLE
pcloPanel fin. HPL Lamitak Mood Cloudy Cement DXP 1387BS

Kodenya pendek supaya gampang diingat: jenis barang, lalu 3 huruf pertama materialnya. Panel Cloudy Cement jadi pclo. Huruf besar/kecil tidak berpengaruh.

SL / SLSCALEMenaruh spec leader

  1. Penyebut skala, misalnya 15 untuk 1:15. Hanya ditanyakan pertama kali di satu sesi.
  2. Kode spec, misalnya pclo. Tekan Enter untuk melewatinya dan mendapat block SPEC kosong.
  3. Klik titik di objek. Titik ini menjadi pusat lingkaran.
  4. Klik titik pertama leader, lalu titik-titik berikutnya. Enter untuk selesai.

Lingkaran, garis putus-putus, dan block SPEC mengikuti skala. SLSCALE mengganti skalanya saat pindah ke gambar lain.

RR / RZ / RCMenggambar ulang leader setelah dipindah

Pindahkan lingkaran atau block SPEC ke mana saja, lalu pilih salah satu bagian grupnya. Leader lama dihapus dan diganti yang baru.

  • RR menggambar garis lurus kalau SPEC sejajar dengan pusat lingkaran. Kalau tidak, bentuknya L: naik atau turun dari lingkaran, lalu mendatar ke SPEC.
  • RZ selalu menggambar bentuk Z: mendatar dari lingkaran, belok vertikal di tengah, lalu mendatar ke SPEC.
  • RC menggambar bentuk C: keluar dari lingkaran di sisi yang berlawanan dengan SPEC, belok vertikal, lalu kembali mendatar ke SPEC.

EEMenghapus satu grup leader

Pilih lingkaran, leader, atau block SPEC, dan ketiganya dihapus.

CSMenyalin deskripsi spec

Menyalin SPECDESC dari satu block SPEC ke block yang diklik. Enter untuk selesai. Hanya deskripsi yang berubah; kode di block tujuan tetap.

SYMengganti spec di seluruh gambar

Untuk saat klien mengganti material. Masukkan kode lama dan kode baru. SY mencari kedua deskripsinya di TOC, lalu mengganti setiap block SPEC yang deskripsinya sama dengan yang lama, di model space dan di semua layout. Di akhir, SY memberi tahu berapa block yang diganti.
