AutoLISP for AutoCAD

LSP Suite

AutoLISP commands for interior drafting. They take care of the repetitive parts: numbering sheets, keeping titles in sync with the table of contents, and drawing spec leaders that stay linked to their labels.

Why I built this

Interior shop drawings repeat the same small jobs hundreds of times. Every sheet gets a code and a title, typed once in the table of contents and again on the sheet. Every material gets a leader and a description. When a sheet is added or a client changes a material, all of it is redone by hand.

These commands are built around one idea: the table of contents in model space is the single source of truth. Sheet codes, layout names, sheet titles and material descriptions are typed once in the TOC, and the commands copy them everywhere else. Spec leaders keep a hidden link between their three parts, so they can be moved, redrawn or swapped across the whole drawing in one step.

I'm an interior drafter. I designed each command: what it does, what it asks, and how it fits the way a drawing set gets made. I built them with AI coding agents and use them on real projects.

How to use

Load the .lsp files with APPLOAD. Then type a command name in the command line and press Enter, the same way you'd type LINE or COPY.

Most commands look for blocks and attributes by name. The block reference at the bottom lists them.

Quick tools

Type the command and answer the prompts.

ADNumber blocks in click order

Pick a source block, then click other blocks one at a time. Every number in every attribute goes up by the step times the click count. With step 1, the 1st click gets +1, the 2nd +2, and so on. The target's current value is ignored. Leading zeros are kept, so FURN-01 becomes FURN-02.

  1. Step per click. Enter gives 1. Negative works.
  2. Pick the source block.
  3. Click targets in order. Enter to finish.

Scale attributes (SKALA) are never touched.

CCCopy a drawing title

Copies the drawing title from one JUDUL block to others. JUDUL is the title label under each drawing in model space.

  1. Pick the source JUDUL block.
  2. Click the targets. Enter to finish.

DBFrame and title for a new drawing

Draws a page frame on the Defpoints layer, which doesn't plot, and puts a JUDUL2 title block in its centre. Both are sized for the scale you give: the frame is 340 × 287 times the scale, so 6800 × 5740 at 1:20.

  1. Scale denominator, for example 20 for 1:20. DB remembers your last answer.
  2. Drawing title. Type s, v, d or f for SECTION 1-1, VIEW 1, DETAIL A or FRONT VIEW. Anything else is used exactly as typed. Enter leaves it blank.
  3. Click the top-left corner of the frame.

The title block gets the title and the scale, written as 1:20.

DDSwitch the dimension scale

Sets the dimension scale (DIMSCALE). Select dimensions before running DD and they switch to the new scale too.

Prompt: the scale, for example 50 for 1:50.

DIVV / DIVHSplit a box into equal compartments

For cabinet elevations. DIVV adds vertical dividers, DIVH adds horizontal shelves. Each divider is drawn as two lines one thickness apart, and every clear opening comes out the same size.

  1. Number of compartments. Default 3.
  2. Divider thickness. Default 20.
  3. Pick the cabinet outline.

DSTaper lines for a rounded edge

Draws parallel lines next to a reference line, with gaps that grow by a ratio. That's the usual way to show a curved surface in elevation.

  1. Pick the reference line.
  2. Number of lines. Default 8.
  3. Growth ratio. Default 1.35.
  4. Distance to the last line. The sign picks the side. Default 100.

Your answers become the defaults for the next run.

NUMRow of numbers

Writes numbers as text in a row, left to right, on the current layer and text style.

Prompts: how many numbers, start number (Enter gives 1), start point.

PFPlace the furniture list

Builds the furniture list on the index page of a furniture shop drawing set. Inserts a column of FURNLIST blocks with codes like CA1, CA2... and titles like cabinet 1, cabinet 2....

Prompts: code prefix, title base, start number, end number, first insertion point.

QSwitch layer with one letter

Type a letter and that layer becomes current. Select objects before running Q and they move to that layer instead, and the current layer stays as it was.

TOC and layouts

These commands treat the table of contents in model space as the master list of sheets. You type each sheet title once in the TOC, and the commands copy it onto the title block of the matching layout.

The TOC block

A TOC is a column of TOC blocks in model space. Each one is a row with two attributes:

TagHoldsExample
PAGECODESheet code. Must match the layout tab name (case doesn't matter).FURN-03
PAGETITLESheet title shown on the title block.Cabinet 3 elevation

TOC blocks also hold the spec codes that SL reads. That's covered in spec codes.

Workflow

Start with one layout per sheet, in the right order.

  1. Place the rows. In model space run PT with prefix FURN, start 1, end 12. You get FURN-01 to FURN-12 with empty titles.
  2. Fill in titles. Double-click the first row and type the title. Then use CT to copy it as-is, or CP / CPP to copy it with the number going up on each click.
  3. Rename the layouts. Run WQB with prefix FURN- and start 1. The tabs become FURN-01 to FURN-12, matching the TOC.
  4. Sync each sheet. Set the viewport scale, then run WS on the layout. It writes the scale and pulls the title from the TOC. For not-to-scale sheets run WSS.
  5. Inserting a sheet later. Select the rows after the new one and run CTB with +1 to shift their codes. Run WQB again, then WS on the affected sheets.

PTPlace TOC rows

Inserts a column of TOC blocks with codes FURN-01, FURN-02... and blank titles.

Prompts: prefix, start number, end number, first insertion point.

CT / CP / CPPCopy a TOC title

All three copy PAGETITLE from a source TOC block to the blocks you click next. Pick the source, click targets, Enter to finish. They differ in what happens to numbers in the title:

CommandNumbersSource Level 2 Cabinet 4 gives
CTunchangedLevel 2 Cabinet 4, Level 2 Cabinet 4...
CPall +1 per clickLevel 3 Cabinet 5, Level 4 Cabinet 6...
CPPall but the first +1 per clickLevel 2 Cabinet 5, Level 2 Cabinet 6...

CW / CTBChange TOC codes

CW works like CP but on PAGECODE: pick a source, and each target gets the code +1, +2 and so on. Padding is kept, so FURN-09 gives FURN-10.

CTB is the batch version. Window-select any number of blocks, give an amount (default 1, negative allowed), and it adds that to the number at the end of each code. FURN-05 becomes FURN-06.

WQBRename all layouts

Renames every layout tab in tab order to prefix + number, padded to two digits.

Prompts: prefix (can be blank), start number.

WS / WSSSync scale and title onto a sheet

Run it on a layout tab. No prompts.

  1. Scale. WS reads the viewport's scale and writes 1:50 (or whatever it is) into the title block's SCALE attribute. WSS writes N.T.S instead.
  2. Title. Finds the TOC block in model space whose PAGECODE matches this tab's name and writes its PAGETITLE into KOPTITLE on the title block.

Specs and leaders

How a spec leader works

A spec leader is three objects: a small circle on the thing you're labelling, a dashed polyline, and a SPEC block showing the code and description. SL draws all three and stamps them with a shared hidden ID (XData). That ID lets RR, RZ, RC and EE find the other two when you pick any one of them.

Copying a leader copies its ID too, so new leaders always come from SL.

Spec codes

SL fills in the description by looking up the spec code in the TOC blocks in model space. Each material gets one TOC row: the code goes in PAGECODE, the full description in PAGETITLE.

PAGECODEPAGETITLE
pcloPanel fin. HPL Lamitak Mood Cloudy Cement DXP 1387BS

Codes are short so they're easy to remember: the item, then the first 3 letters of the material. Cloudy Cement on a panel becomes pclo. They aren't case-sensitive.

SL / SLSCALEPlace a spec leader

  1. Scale denominator, for example 15 for 1:15. Only asked the first time in a session.
  2. Spec code, for example pclo. Press Enter to skip it and get an empty SPEC block.
  3. Click a point on the object. That becomes the circle centre.
  4. Click the first leader point, then more points. Enter to finish.

The circle, dashes and SPEC block are sized for the scale. SLSCALE changes the scale when you move to another drawing.

RR / RZ / RCRedraw a leader after moving things

Move the circle or the SPEC block wherever you like, then pick any part of the group. The old leader is deleted and a clean one is drawn.

  • RR draws a straight line if the SPEC is level with the circle centre. Otherwise it draws an L: up or down out of the circle, then across into the SPEC.
  • RZ always draws a Z: across out of the circle, a vertical jog halfway, then across into the SPEC.
  • RC draws a C: out of the circle on the side away from the SPEC, a vertical jog, then back across into the SPEC.

EEErase a whole leader group

Pick the circle, leader or SPEC block and all three are deleted.

CSCopy a spec description

Copies SPECDESC from one SPEC block to the ones you click. Enter to finish. Only the description changes; the code on the target stays as it was.

SYSwap a spec across the drawing

For when the client changes a material. Enter the old code and the new code. SY looks up both descriptions in the TOC, then replaces every SPEC block whose description matches the old one, in model space and on every layout. At the end it tells you how many blocks it changed.
